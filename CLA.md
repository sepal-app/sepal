## How to sign

You do not need to send anything by email or post a physical signature.

When you open your first pull request against `sepal-app/sepal`, a bot will
comment on it asking you to sign. Reply on that pull request with a comment
containing exactly this sentence:

```
I have read the CLA Document and I hereby sign the CLA
```

Your GitHub username, the date, and the pull request number are recorded in
`signatures/version1/cla.json` in this repository. You sign once; later pull
requests are checked against that record automatically.

If the check does not update after you sign, comment `recheck` on the pull
request.
